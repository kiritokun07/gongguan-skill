# 两阶段回应行动包

本模板用于组织内容，不要求每次输出所有栏目。只生成当前阶段和实际渠道需要的材料。

## 一、第一阶段：止损与核实卡

首次响应在开头原样显示：

> 本 Skill 仅提供艺人舆情研判与公共沟通辅助，不构成法律、经纪、平台治理、医疗、心理危机或人身安全专业意见。涉及违法犯罪、性侵害、未成年人、毒品、自伤或严重安全风险时，应停止发布并立即交由相应专业人员处理。

随后按以下顺序输出：

### 1. 适用性和风险

- 是否属于本 Skill 范围。
- 是否触发高风险停止门槛。
- 当前最可能的事实状态、公众责任归因和传播风险。
- 明确哪些判断只是条件式推断。

### 2. 立即暂停或保护

只列当前必要动作，例如：

- 暂停尚未发布的回应、预设宣传内容和粉丝协同指令。
- 指定唯一事实底稿和内部信息负责人。
- 保存原帖链接、原始文件、完整音视频、发布时间和团队已发布内容。
- 限制含非公众人物、家属、住址、行程、健康或家庭信息的材料流转。
- 不删除记录、不私下施压、不让粉丝代为试探口风。

不要把“立刻发声明”默认成止损动作。

### 3. 关键证据

列出已经拥有、仍需取得以及不可公开的证据。每项注明它会影响哪条事实或哪项策略。

### 4. 关键问题

最多七个，只问答案会改变停止判断、事实状态或回应策略的问题。优先询问核心主张、原始证据、艺人本人确认、受影响者、既有表态和审批人。

### 5. 初步回应方向

从“不回应、保持声明、事实纠正、有限承认、正式道歉”中给出一个主方向和改换策略的触发条件。证据不足时不要生成正式声明。

仅当外部确有即时知情需要、传播正在扩大且完整事实尚未核清时，才提供保持声明；保持声明也必须经过内部审批。

## 二、第二阶段：正式行动包

所有正式行动包和声明草稿在开头原样显示：

> 以下内容基于当前提供且可能不完整的信息，仅供艺人工作室或经纪团队内部研判和草拟沟通材料。发布前必须由事实负责人、经纪负责人及必要的法务人员审核；不得将未经核实的信息作为事实发布。

### 1. 策略摘要

用简洁条目说明：

- 推荐主策略和目标。
- 已核实的核心事实与尚未核实的主张。
- 公众责任归因及历史、人设强化因素。
- 最大的隐私、可信度和二次传播风险。
- 改换策略的触发条件和下一复核节点。

每条策略理由注明它来自事实矩阵、责任归因或形象修复原则中的哪一项。

### 2. 利益相关者顺序

按实际伤害而非声量排序，并分别写出信息需求和不应披露的内容：

1. 直接受影响者。
2. 非公众人物、家属及其他需要保护的人。
3. 公众或活动参与者。
4. 粉丝。
5. 平台、媒体及确有知情需要的合作方。

私人生活事件中，第三方和家属的隐私优先于粉丝好奇、媒体追问和人设维护。

### 3. 统一事实底稿

所有渠道从同一底稿提取：

- 可以公开的已证实事实。
- 明确不能公开的敏感信息。
- 尚未证实、不得写入声明的主张。
- 团队已经采取且可以验证的动作。
- 下一次复核或更新条件。

任何渠道不得自行增加事实、责任、承诺或对他人动机的判断。

### 4. 核心信息结构

根据策略选择必要元素：

- 发生了什么：只写已经核实且可以公开的事实。
- 对谁造成了什么影响：受影响者优先，不以团队损失替代。
- 立场：纠正、承认、道歉或隐私边界，避免模糊混用。
- 行动：已经完成或确认会完成的具体动作。
- 未知项：诚实标明仍在核验的内容。
- 后续：给出更新触发条件或正式联系窗口；没有确定时间时不要编造时间。

## 三、按需生成渠道版本

### 工作室声明

用于呈现事实、核验过程、团队动作和联系窗口。语气专业、克制，不借工作室口吻替艺人表达不存在的个人情感。结构通常为：

1. 回应的具体事项。
2. 可公开的已证实事实。
3. 对错误信息的精确纠正，或对已确认问题的责任与行动。
4. 隐私边界和必要联系窗口。
5. 下一复核节点。

### 艺人本人回应

只在个人态度、责任或承诺确有必要，而且艺人确认内容时生成。使用第一人称，避免工作室公文腔。不得：

- 把责任全部推给团队、粉丝、媒体或“表达方式”。
- 要求公众理解、原谅或停止讨论。
- 用成长经历、压力或情绪替代责任。
- 承诺艺人本人并不接受或无法做到的改正行动。

### 媒体问答

只覆盖可预见且有可靠底稿的问题。每题包含：

- 可公开回答。
- 不能回答时的真实原因，例如仍在核验或涉及第三方隐私。
- 禁止扩展的未经核实内容。

不要把“无可奉告”当作通用答案，也不要暗示未能公开的信息可以证明艺人清白。

### 合作方说明

仅在合作方确有决策需要时生成。说明已核实事实、当前动作、潜在影响和下一更新时间；不要求合作方公开背书，也不提供超出其知情需要的私人信息。

### 粉丝信息与降温

粉丝侧只可同步公开事实和边界：

- 以工作室正式信息为准，不传播未核实截图和私人信息。
- 不攻击、私信骚扰、人肉或举报相关方。
- 不统一文案刷屏、不控评、不制造“路人”背书。
- 不代替艺人或工作室作事实承诺。

不得为后援会、大粉或粉丝群设计传播任务、暗语、反串或对外施压计划。

## 四、私人生活事件专用检查

在恋情、婚姻、家庭和偷拍视频事件中，先问“回应是否存在正当公共利益”，而不是默认满足好奇心。

- 无公共伤害且事实不明：优先不回应。
- 传播已经影响非公众人物安全或出现具体错误：使用最小化的边界声明或事实纠正。
- 不公开第三方姓名、工作单位、住址、行程、健康、聊天记录、亲密影像或家庭细节。
- 不为维持单身、恋爱或家庭人设编造关系状态。
- 不利用偷拍视频、跟拍或私密材料反向炒作。
- 回应范围只覆盖需要纠正或保护的部分，不把“自证”变成更多隐私披露。

## 五、发布前检查

任何正式草稿交付前逐项检查：

- [ ] 没有触发高风险停止门槛。
- [ ] 每个事实都出现在统一底稿中，并标明可公开。
- [ ] 工作室、艺人、媒体问答和合作方版本没有事实冲突。
- [ ] 没有把网友推测、媒体转述或当事人单方主张写成已证实事实。
- [ ] 没有泄露或暗示非公众人物、家属及其他第三方的敏感信息。
- [ ] 纠正有相应证据；道歉有明确责任、影响和可验证行动。
- [ ] 没有条件式道歉、责怪受众、攻击爆料者或要求原谅。
- [ ] 没有控评、刷屏、举报、网暴、水军、反串或虚假背书安排。
- [ ] 艺人本人确认第一人称回应中的事实、态度和承诺。
- [ ] 事实负责人、经纪负责人及必要法务已被列为发布前审批人。
- [ ] 正式免责声明完整保留。

如果任何关键项不能通过，将草稿标为“不可发布”，指出缺口并退回第一阶段，不用模糊占位词掩盖问题。
