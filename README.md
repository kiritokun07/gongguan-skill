# 公关 Skill

面向中国大陆艺人工作室和经纪团队的舆情研判 Skill。它帮助团队在事实不完整、讨论快速扩散时，先判断是否应该回应，再形成克制、可核验、可审批的沟通方案。

它不是“洗白”、控评或热搜操盘工具，也不保证公众接受任何回应。

> **免责声明：** 本 Skill 仅提供艺人舆情研判与公共沟通辅助，不构成法律、经纪、平台治理、医疗、心理危机或人身安全专业意见。正式内容发布前必须由事实负责人、经纪负责人及必要的法务人员审核。

## 适用范围

- 艺人旧言论、公开失言、活动表现和一般网络质疑。
- 信息误传、身份误认及有条件核验的事实性谣言。
- 粉丝冲突及艺人被卷入的饭圈争议。
- 恋情、婚姻、家庭、偷拍视频等私人生活传闻中的公共沟通与隐私边界。

## 不适用范围

- 作品评价、番位、抄袭、代言、合同、劳动关系和商业纠纷。
- 普通企业危机或与艺人个人声誉无关的事项。
- 刑事指控、性侵害、未成年人、毒品、自伤、正在发生的威胁或严重人身安全事件。

最后一类事件会触发停止门槛：Skill 不再生成声明或声誉修复策略，只提供安全提醒、证据保护和专业升级清单。

## 如何使用

在 Codex 中调用 `$gongguan-skill`，并尽量提供事件原始内容、发生时间、消息来源和团队已经做过的回应。例如：

```text
使用 $gongguan-skill 帮我研判这起艺人舆情，先判断是否应该回应。

昨晚某账号发布了一段艺人三年前活动现场的剪辑，称艺人对工作人员态度恶劣。
目前只有剪辑视频，没有完整录像；工作室尚未回应，相关话题正在微博扩散。
```

也可以先提供很少的信息。Skill 会优先指出需要暂停和保存的事项，再提出最多七个会改变策略的关键问题，不会为了快速出稿而补写事实。

## 两阶段工作流

### 第一阶段：止损与核实

输出包括：

- 适用性和高风险停止检查。
- 当前事实可信度、公众责任归因和传播风险。
- 立即暂停或保护的事项。
- 需要保存的证据和关键问题。
- “不回应、保持声明、事实纠正、有限承认、正式道歉”中的初步方向。

### 第二阶段：可审批回应包

只有核心事实足够支撑策略时，才按需生成：

- 策略摘要和利益相关者排序。
- 统一事实底稿与核心信息结构。
- 工作室声明、艺人本人回应和媒体问答。
- 必要的合作方说明和粉丝降温建议。
- 发布前审批与隐私检查表。

所有渠道共用同一事实底稿。未经核实的主张不会被写成事实，私人生活事件优先保护非公众人物和家属。

## 决策原则

Skill 以公关学知识为判断基础，主要参考：

- SCCT 情境危机沟通理论：分析公众如何归因责任，以及历史争议和既有声誉如何放大风险。
- Benoit 形象修复理论：在事实纠正、有限承认、承担责任和补救等路径间作选择。
- 公众人物道歉研究：检查道歉是否具体、真诚，并有可验证的改正行动。

详细理论、适用限制和学术来源见 [公关理论与决策规则](references/pr-theory.md)。

## 安全边界

本 Skill 不会：

- 伪造证据、聊天记录、关系状态或第三方背书。
- 泄露或暗示非公众人物、家属及其他第三方的敏感信息。
- 设计水军、控评、刷屏、举报、网暴、反串或粉丝攻击方案。
- 用“公众误解”“断章取义”等套话回避已经核实的责任。
- 承诺“压下热搜”“洗白”、获得原谅或保证舆论结果。
- 自行发布、删帖、联系媒体、动员粉丝或操作平台。
